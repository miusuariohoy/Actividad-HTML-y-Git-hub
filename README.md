# 📚 Plataforma Web Docente: Guía y Desafío de Desarrollo Web Inicial

Página web lista para publicar en **GitHub Pages**. Sirve como el material didáctico oficial e interactivo para que los estudiantes aprendan HTML5, conozcan los requisitos de la actividad práctica y aprendan a interactuar con la IA para generar el CSS de sus propios sitios.

## 🚀 Publicación Rápida en GitHub Pages (Para el Docente)

1. En tu cuenta de GitHub, crea un nuevo repositorio público llamado, por ejemplo: guia-web-inicial.
2. Sube los dos archivos principales de esta carpeta:
   - index.html (La guía interactiva completa).
   - estilos.css (El diseño visual moderno y responsivo).
3. Ve a **Settings > Pages** en GitHub.
4. En **Branch**, elige main (o master) y la carpeta /(root). Presiona **Save**.
5. ¡Listo! En 1 minuto tendrás la URL pública para compartir en el aula virtual o proyector:
   https://tu-usuario.github.io/guia-web-inicial/

## 👥 ¿Qué verán los alumnos al entrar?
- **Apartado Teórico Completo:** Explicación analógica de HTML, estructura base, glosario de etiquetas y maquetación semántica HTML5 con diagramas.
- **Consigna Práctica Clara:** Requisitos para que **ellos construyan su propia web** de 2 páginas con menús de navegación.
- **Laboratorio de IA:** El prompt modelo para pedirle a ChatGPT/Claude el CSS de su proyecto, con advertencias docentes sobre no copiar sin entender.
- **Guía de GitHub Pages para Alumnos:** Instrucciones paso a paso para que suban su trabajo y te entreguen su propio enlace en vivo.
