1 · Teoría: formularios en HTML5

1. ¿Qué es un formulario?

Un formulario permite pedir datos al visitante y enviarlos a un servidor. Se arma con <form> y adentro van los campos: texto, contraseñas, opciones, listas, casillas y botones.

Importante: HTML solo arma la interfaz y envía los datos. Para guardarlos o validarlos de verdad hace falta un lenguaje del lado del servidor.

2. Estructura básica: form, action y method

<form> es el contenedor de todos los campos. Dos atributos clave:

AtributoQué haceEjemplo
actionIndica a dónde se envían los datosaction="/guardar.php"
methodCómo se envían: get o postmethod="post"

get manda los datos en la URL (útil para búsquedas). post los manda en el cuerpo de la petición (para contraseñas o datos largos).

<form action="/guardar.php" method="post">
  ...campos...
</form>

3. Los cuatro atributos que más se usan: id, for, name y type

Estos cuatro atributos son los que más confunden. Cada uno hace una cosa distinta:

AtributoDónde vaPara qué sirveEjemplo
id En el campo (input, select o textarea) Le da un nombre único dentro de la página. Es como el DNI del campo: no se puede repetir. El label lo usa para encontrarlo. id="correo"
for En el <label> Dice a qué id pertenece esa etiqueta. Tiene que ser igual al id del campo. Así, al hacer clic en el texto, el campo se activa y un lector de pantalla lo anuncia. for="correo"
name En el campo (input, select o textarea) Es el nombre con el que se envía el dato al servidor. Aparece en la URL o en el cuerpo del mensaje. Sin name, el dato no se envía. Puede repetirse (los radio lo necesitan). name="correo"
type Solo en <input> Define qué tipo de campo es: texto, contraseña, correo, número, fecha, casilla, botón… El navegador lo dibuja y lo valida según el tipo. type="email"

Ejemplo de los cuatro juntos:

<label for="correo">Correo:</label>
<input id="correo" type="email" name="correo" placeholder="tu@correo.com" required>
  • for="correo" y id="correo" coinciden → el texto «Correo:» pertenece a ese input.
  • type="email" → el navegador espera un correo y avisa si falta la @.
  • name="correo" → cuando se envíe, el servidor recibirá algo como correo=ana@mail.com.
  • placeholder es solo una pista; required obliga a completarlo.
Truco para recordarlo: id y for son pareja (etiqueta ↔ campo) y deben ser iguales. name y type son del campo: uno nombra el dato que viaja y el otro define el tipo de caja.

4. Tipos de input más usados

typePara qué sirveEjemplo en tu formulario
textTexto simple (es el valor por defecto)nombre, apellido, nacionalidad, curso, división
passwordContraseña: los caracteres se ocultan(no hace falta acá)
emailCorreo: valida que tenga @(si querés agregar un correo)

5. Radio y checkbox

Los radio comparten el mismo name para que solo se pueda elegir uno. Los checkbox pueden marcarse varios.

<input type="radio" id="visa" name="pago" value="visa">
<label for="visa">Visa</label>
<input type="radio" id="efectivo" name="pago" value="efectivo">
<label for="efectivo">Efectivo</label>

<input type="checkbox" id="news" name="news">
<label for="news">Quiero recibir novedades</label>

Los radio también sirven para elegir una sola opción entre varias, por ejemplo la especialidad (Básico, Programación o Informática): los tres llevan el mismo name="especialidad" y cada uno su id distinto.

6. Listas desplegables y texto largo

<select> arma una lista de opciones con <option>. <textarea> permite escribir varias líneas (y sí lleva etiqueta de cierre).

<label for="pais">País:</label>
<select id="pais" name="pais">
  <option value="ar">Argentina</option>
  <option value="uy">Uruguay</option>
</select>

<label for="mensaje">Mensaje:</label>
<textarea id="mensaje" name="mensaje" rows="4"></textarea>

7. <fieldset> y <legend>: agrupar campos

<fieldset> es un recuadro que agrupa campos que van juntos (por ejemplo, todos los datos de contacto o todas las opciones de pago). <legend> es el título de ese recuadro y siempre va como primer hijo del fieldset.

¿Para qué sirve? Para que el formulario sea más fácil de leer y para que un lector de pantalla anuncie: «Datos de contacto, grupo» antes de leer los campos. Si querés que tu formulario se llame «Datos personales», poné <legend>Datos personales</legend> como primer hijo del fieldset.

<fieldset>
  <legend>Datos de contacto</legend>

  <label for="tel">Teléfono:</label>
  <input id="tel" type="tel" name="tel">

  <label for="correo2">Correo:</label>
  <input id="correo2" type="email" name="correo2">
</fieldset>

El botón <button type="submit">Enviar</button> es el que dispara el envío de todo el formulario.

8. Accesibilidad: resumen

  • Todo campo lleva un <label> con for = id.
  • No uses solo el placeholder como etiqueta: desaparece al escribir.
  • Marcá con required los campos obligatorios. Si todos lo son, agregalo en cada input, en el select y en el textarea.
  • Agrupá opciones con fieldset + legend.
  • Dentro de un grupo de radio, required alcanza con ponerlo en uno para que se exija elegir una opción.

2 · Ejemplo completo

Así se ve y así se escribe un formulario de contacto:

Tema

Ejemplo: este formulario es solo demostrativo: al hacer clic en «Enviar» no se envía nada a ningún servidor.

<form action="/guardar.php" method="post">
  <label for="nombre">Nombre:</label>
  <input id="nombre" type="text" name="nombre" placeholder="Tu nombre" required>

  <label for="correo">Correo:</label>
  <input id="correo" type="email" name="correo" placeholder="tu@correo.com" required>

  <fieldset>
    <legend>Tema</legend>
    <input id="consulta" type="radio" name="tema" value="consulta">
    <label for="consulta">Consulta</label>
    <input id="soporte" type="radio" name="tema" value="soporte">
    <label for="soporte">Soporte</label>
  </fieldset>

  <label for="mensaje">Mensaje:</label>
  <textarea id="mensaje" name="mensaje" rows="3"></textarea>

  <button type="submit">Enviar</button>
</form>

3 · Ejercitación autocorregible

Escribí el código HTML en cada cuadro y presioná ✅ Corregir.

✍️ Ejercicio 1.1: etiqueta y campo Fácil

Armá un formulario con un <label> para «Nombre» y un <input type="text">. El for debe coincidir con el id. El texto del label tiene que decir «Nombre».

✍️ Ejercicio 1.2: tipos y atributos Medio

Usá tres campos: email, password y number. Los tres deben tener name, required y su propio <label> con for = id.

✍️ Ejercicio 1.3: una opción y una casilla Medio

Escribí un radio y un checkbox, cada uno con su <label> usando for = id.

✍️ Ejercicio 1.4: lista, texto largo y envío Difícil

Usá un <select> con dos <option>, un <textarea> y un <button type="submit">. Todos los campos con name y con su <label> usando for = id.

4 · Actividad guiada: publicá tu formulario y entregá el link

Seguí estos pasos para crear tu propio formulario, subirlo a GitHub y entregarlo.

1

Creá tu proyecto: formulario «Datos personales»

En tu computadora hacé una carpeta con dos archivos: index.html (tu formulario) y estilos.css. Todo el HTML va dentro de un <form>. Adentro lleva un <fieldset> con <legend>Datos personales</legend> y estos campos, todos obligatorios con required:

CampoEtiqueta visibletype / control
nombreNombre:text
apellidoApellido:text
dniDNI:number
fecha_nacFecha de nacimiento:date
nacionalidadNacionalidad:text
cursoCurso:text
divisionDivisión:text
especialidadEspecialidad:radio: Básico, Programación o Informática (mismo name)

Cada campo lleva su <label> con for = id, su name y required. Cerrá con <button type="submit">Enviar</button>. El CSS lo vas a pedir recién en el paso siguiente.

Observación opcional: acá usamos type="number" para el DNI porque es simple. Como mejora avanzada podés usar type="text" inputmode="numeric": evita decimales y no pierde ceros a la izquierda.

2

Pedile el CSS a una IA

Copiá todo el código de tu index.html y pegalo en una IA (ChatGPT, Gemini, Claude…). Pedile el estilos.css con el diseño que quieras. Por ejemplo:

Actuá como diseñador web. Este es mi formulario HTML:
[pegá acá todo tu index.html]

Generá un archivo estilos.css con paleta roja, etiquetas arriba de
cada campo, bordes redondeados, botón rojo y diseño adaptable a celular.
Comentá cada regla explicando para qué sirve.

Después pegá lo que te devuelva en tu archivo estilos.css, guardalo y recargá la página para ver el resultado. Probá cambiar algún color o margen: la IA te ayudó, pero el criterio es tuyo.

3

Creá el repositorio y subí los archivos

Entrá a github.com, iniciá sesión y hacé clic en New repository. Llamalo por ejemplo mi-formulario-html, marcalo como Public y subí index.html y estilos.css con Commit changes.

4

Activá GitHub Pages

En tu repo andá a Settings → Pages. En Branch elegí main y carpeta /(root), y presioná Save.

5

Copiá tu link público

Esperá 1 o 2 minutos y abrí https://tu-usuario.github.io/mi-formulario-html/. Ese es el link que tenés que entregar.

6

Entregá el link

Antes de entregar, revisá esta checklist:

  • ☐ El link abre y muestra tu formulario (probalo vos primero).
  • ☐ Todo está dentro de <form> y los campos dentro del <fieldset>.
  • ☐ Cada campo tiene <label> con for = id.
  • ☐ Cada campo tiene name y los obligatorios, required.
  • ☐ El <fieldset> empieza con <legend>Datos personales</legend>.
  • ☐ Cerrás con <button type="submit">Enviar</button>.
  • ☐ Probaste la página en el celular o con la vista móvil del navegador.

Completá el formulario de abajo con tu nombre, apellido, curso y el link de tu página. La entrega se guarda como Entrega HTML Formularios en el repositorio inform, junto con tus datos. Puede tardar unos minutos en aparecer en el informe.

Datos de la entrega

Privacidad: guardamos nombre, apellido, curso, link y fecha de envío. El envío usa un canal público con el contenido cifrado; no pedimos contraseñas ni datos sensibles.
