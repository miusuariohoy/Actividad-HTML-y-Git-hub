01

Apartado Explicativo: Fundamentos de HTML & HTML5

Todo lo que necesitas conocer antes de escribir tu primera línea de código.

1. ¿Qué es HTML y cuál es su función?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). No es un lenguaje de programación (no tiene bucles, variables ni lógica matemática), sino un lenguaje de marcado de estructura.

💡 La analogía de la construcción:

  • HTML: Es el esqueleto, los ladrillos, vigas, puertas y ventanas de una casa. Define dónde va cada cosa.
  • CSS: Es la pintura, la decoración, el color de las cortinas y el estilo arquitectónico.
  • JavaScript: Es el sistema eléctrico inteligente: luces que se encienden al presionar un botón, sensores y timbres.

2. Estructura básica de un documento HTML5

Todo archivo HTML válido debe contener esta estructura base obligatoria:

<!DOCTYPE html>
<html lang=es>
<head>
    <meta charset=UTF-8>
    <meta name=viewport content=width=device-width, initial-scale=1.0>
    <title>Título de mi Pestaña</title>
    <!-- Aquí vinculamos la hoja de estilos externa -->
    <link rel=stylesheet href=estilos.css>
</head>
<body>
    <!-- Todo el contenido visible para los usuarios va aquí adentro -->
</body>
</html>
Etiqueta / Elemento ¿Para qué sirve?
<!DOCTYPE html> Le avisa al navegador que el documento sigue la versión moderna HTML5.
<html lang=es> Elemento raíz que envuelve todo el sitio. El atributo lang=es define el idioma en español.
<head> Contiene metadatos, configuración técnica y enlaces a recursos (no se muestra en el cuerpo visual de la página).
<meta charset=UTF-8> Permite visualizar correctamente caracteres especiales, tildes, signos y la letra ñ.
<meta name=viewport...> Permite que la página se adapte al ancho de pantallas móviles y tablets.
<title> El nombre que se ve en la pestaña del navegador o en los resultados de Google.
<body> El contenedor de todo el contenido visible: textos, imágenes, videos y botones.

3. Etiquetas esenciales de contenido

Encabezados (Títulos)

Van desde <h1> (el más importante) hasta <h6> (el menor nivel). Regla de oro: solo un <h1> por página.

<h1>Título Principal</h1>
<h2>Subtítulo de Sección</h2>

Párrafos y Formato

<p> define párrafos de texto. Usa <strong> para texto en negrita y <em> para cursiva o énfasis.

<p>Este es un texto con <strong>negrita</strong>.</p>

Listas Ordenadas y Desordenadas

<ul> para listas con viñetas; <ol> para listas numeradas. Cada ítem va dentro de <li>.

<ul>
    <li>Primer elemento</li>
    <li>Segundo elemento</li>
</ul>

Enlaces (<a>) e Imágenes (<img>)

<a href=...> crea vínculos entre páginas. <img src=... alt=...> inserta imágenes con texto descriptivo obligatorio.

<a href=sobre-mi.html>Ir a Sobre Mí</a>
<img src=img/foto.jpg alt=Foto descriptiva>

4. Maquetación Semántica en HTML5: ¿Por qué es fundamental?

Las etiquetas semánticas tienen un significado claro tanto para el programador como para los navegadores, buscadores (SEO de Google) y lectores de pantalla para personas con discapacidad visual.

<header> : Encabezado del sitio / Logotipo / Título principal
<nav> : Menú de navegación principal (enlaces <a>)
<main> (Contenido central del sitio)
<section> y <article>
Contenido temático y artículos
<aside>
Barra lateral / Datos curiosos
<footer> : Pie de página / Copyright / Redes sociales
  • <header>: Cabecera de la página o de una sección destacada.
  • <nav>: Contenedor exclusivo para los menús de navegación.
  • <main>: El contenido central, único y protagonista de la página (¡solo uno por documento!).
  • <section>: Bloque genérico para agrupar contenido relacionado temáticamente.
  • <article>: Contenido autónomo e independiente (una noticia, ficha de producto o post).
  • <aside>: Información complementaria o secundaria (publicidad, glosario, datos curiosos).
  • <footer>: El pie de página con créditos, año y datos de contacto.
02

Consigna Práctica: ¡Construye tu propio Sitio Web!

Ahora es tu turno de programar. Sigue estos pasos para crear tu web desde cero.

Tu desafío: Crear un sitio web de 2 páginas interconectadas

El tema de la página es libre (puede ser tu Portafolio personal, una web sobre tu banda musical favorita, tu videojuego preferido o un proyecto ecológico).

📋 Requisitos obligatorios del proyecto:

  1. Mínimo dos páginas HTML:
    • index.html (Página principal de bienvenida).
    • sobre-mi.html o proyectos.html (Segunda página de contenido).
  2. Menú de navegación (<nav>): Ambas páginas deben tener un menú idéntico que permita saltar de una página a la otra mediante etiquetas <a href=...>.
  3. Estructura semántica completa: Debes utilizar obligatoriamente <header>, <nav>, <main>, <section>, <article>, <aside> y <footer>.
  4. Contenido rico: Al menos 1 imagen con atributo alt, párrafos con negritas y una lista (<ul> u <ol>).
  5. Hoja de estilos externa: Ambas páginas deben vincularse a un único archivo estilos.css.

Estructura de carpetas recomendada en tu computadora:

mi-sitio-web/
├── index.html        (Tu primera página)
├── sobre-mi.html     (Tu segunda página enlazada)
├── estilos.css       (Aquí irá el CSS que le pedirás a la IA)
└── img/              (Carpeta para colocar tus fotos o imágenes locales)
03

Laboratorio de IA: Diseñando el CSS de tu Web

No programarás el CSS desde cero: aprenderás a ser un director de diseño utilizando IA con criterio técnico.

¿Cómo pedirle el código CSS a una IA?

Una Inteligencia Artificial (ChatGPT, Claude, Gemini, etc.) te dará mejores resultados mientras más específico y técnico sea tu pedido (prompt).

🤖 Prompt Plantilla para Copiar y Personalizar: 
Actúa como un diseñador web frontend experto y docente de CSS.
He creado la estructura de mi sitio web en HTML5 con etiquetas semánticas (<header>, <nav>, <main>, <section>, <article>, <aside> y <footer>) y clases como .contenedor y .tarjeta.

Por favor, genera un archivo completo estilos.css con los siguientes requisitos:
1. Paleta de colores: [Indica tus colores, ej: Fondo gris claro #f8fafc, detalles en azul marino #1e3a8a y acentos en dorado #f59e0b].
2. Tipografía: Una fuente moderna y legible de Google Fonts.
3. Menú de navegación horizontal con efecto :hover suave en los enlaces <a>.
4. Diseño de tarjetas limpias para los <article> con bordes redondeados y sombra suave.
5. Diseño adaptable (responsive) para que se lea bien en celulares.
6. MUY IMPORTANTE: Comenta cada regla CSS explicándome de forma sencilla para qué sirve cada propiedad (margin, padding, border-radius, display: flex, etc.).

⚠️ La Regla de Oro del Desarrollador: Criterio Crítico

¡Prohibido hacer Copiar y Pegar a ciegas!

La IA es tu asistente, no el dueño del proyecto. Tu misión de aprendizaje es:

  • Abrir el archivo estilos.css y leer las explicaciones de la IA.
  • Probar cambiar valores: cambia un color, aumenta un margin o modifica un tamaño de fuente para observar qué sucede en el navegador al recargar (F5).
  • Si la IA incluye algo que no comprendes, pregúntale: ¿Qué significa la propiedad 'box-sizing: border-box' y por qué la pusiste?.
04

Publica tu Proyecto en GitHub Pages

Comparte tu creación con el mundo y entrega tu trabajo final con un link en vivo.

Pasos para publicar tu sitio en minutos:

1

Crea tu cuenta y un nuevo repositorio

Entra a github.com, inicia sesión y haz clic en New repository. Nómbralo (ej: mi-primer-sitio) y asegúrate de marcarlo como Public.

2

Sube tus archivos

Haz clic en uploading an existing file y arrastra todos tus archivos: index.html, sobre-mi.html, estilos.css y la carpeta img/. Haz clic en Commit changes.

3

Activa GitHub Pages

En tu repositorio, ve a ⚙️ Settings > Pages. En la sección Branch, selecciona la rama main y carpeta /(root). Presiona Save.

4

¡Tu web está online!

Espera 1 o 2 minutos. GitHub te entregará tu enlace oficial:
https://tu-usuario.github.io/mi-primer-sitio/. ¡Compártelo con tu docente y compañeros!
